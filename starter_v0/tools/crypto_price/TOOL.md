# crypto_price

Lấy giá hiện tại của các đồng tiền điện tử (cryptocurrency) phổ biến sử dụng public API (ví dụ CoinGecko API).

## Usage
- Tool name: `crypto_price`
- Argument:
  - `coin_id`: ID của đồng tiền (ví dụ: `bitcoin`, `ethereum`, `solana`)
  - `currency`: Đơn vị tiền tệ (ví dụ: `usd`, `vnd`), mặc định là `usd`.

## Example
```json
{
  "coin_id": "bitcoin",
  "currency": "usd"
}
```
